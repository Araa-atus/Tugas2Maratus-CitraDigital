# Tugas 2 Pengolahan Citra Digital

## Metode
Brightness Adjustment (Penyesuaian Kecerahan).

## Deskripsi
Program ini menggunakan Python dan OpenCV untuk mengubah tingkat kecerahan foto.

## Cara Menjalankan
1. Install Python.
2. Install OpenCV dengan perintah `pip install opencv-python`.
3. Letakkan foto asli di folder data dengan nama foto_asli.jpg.
4. Jalankan `python main.py`.
5. Hasil pengolahan tersimpan di folder output.

## Struktur Folder
- main.py: program pengolahan citra.
- data/: foto asli.
- output/: foto hasil Brightness Adjustment.
